# HandshakeAI Chrome Extension 🤝🤖

A powerful Google Chrome extension that leverages Artificial Intelligence to enhance and streamline your experience on the Handshake platform. Whether you are applying for jobs, networking with recruiters, or optimizing your profile, HandshakeAI acts as your personal career assistant right in your browser.

## ✨ Features

* **AI-Powered Message Drafting:** Instantly generate professional, context-aware messages to recruiters and alumni.
* **Smart Application Autofill:** Use AI to parse your resume and seamlessly map your experience to Handshake job applications.
* **Profile Optimization:** Get actionable AI recommendations to improve your Handshake profile visibility and attract more recruiters.
* **Job Fit Analysis:** Automatically compare your skills against job descriptions to gauge your match percentage before applying.

## 🚀 Installation (Developer Mode)

Since this extension is currently in development, you can install it locally using Chrome's Developer Mode.

1. **Clone the repository:**
   ```bash
   git clone <your-github-repo-url>
   ```
2. Open Google Chrome and navigate to `chrome://extensions/`.
3. Enable **Developer mode** by toggling the switch in the top right corner.
4. Click on the **Load unpacked** button in the top left.
5. Select the folder where you cloned this repository. 
6. The HandshakeAI extension should now appear in your list of extensions and in your browser toolbar!

## 💻 Usage

1. Pin the **HandshakeAI** extension to your Chrome toolbar for easy access.
2. Navigate to Handshake.
3. Click the extension icon to open the AI assistant panel.
4. Follow the on-screen prompts to start generating messages, analyzing jobs, or autofilling applications.

## 🛠️ Technologies Used

* **HTML/CSS/JavaScript:** Standard web technologies for the extension popup and content scripts.
* **Chrome Extensions API:** For browser integration and background service workers.
* **AI API:** Powering the core artificial intelligence features.
